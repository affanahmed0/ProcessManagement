# ⚙️ **Process Management System**  
A **Java-based Process Management System** implementing various **CPU scheduling algorithms** to optimize process execution in an Operating System.  

---

## 🚀 **Features**
✅ **Supports Multiple Scheduling Algorithms**  
✅ **Real-time Process Execution Simulation**  
✅ **Runtime Process Calculations (Turnaround, Waiting Time, etc.)**  
✅ **User-Friendly Interface for Process Input**  
✅ **Detailed Logs & Performance Analysis**  

---

## 🛠 **Tech Stack**
- **Language**: Java  
- **Concepts**: CPU Scheduling, Process Management  
- **Algorithms**: FCFS, SJF, Round Robin, Priority Scheduling  
- **Tools**: Eclipse/IntelliJ, JDK 11+  

---

## 📥 **Installation**
1. **Clone the Repository**  
   ```sh
   git clone https://github.com/affanahmed0/ProcessManagement.git
   cd ProcessManagement
   ```
2. **Open the Project in an IDE**  
   - Use **Eclipse** or **IntelliJ IDEA**.  
   - Ensure JDK 11+ is installed.  

3. **Compile and Run the Project**  
   ```sh
   javac *.java
   java Main
   ```

---

## 🎮 **Usage**
- **Select Scheduling Algorithm** from the menu.  
- **Input Process Details** (Arrival Time, Burst Time, Priority, etc.).  
- **View Execution Order** and analyze results.  
- **Compare Performance Metrics** of different algorithms.  

---

## 📊 **Implemented Scheduling Algorithms**
| Algorithm | Type | Preemptive Support |
|-----------|------|--------------------|
| **FCFS** (First Come, First Serve) | Non-Preemptive | ❌ |
| **SJF** (Shortest Job First) | Both | ✅ |
| **Round Robin** | Preemptive | ✅ |
| **Priority Scheduling** | Both | ✅ |
